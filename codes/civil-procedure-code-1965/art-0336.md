# Article 336: Security in case of order for execution
Where an order is made for the execution of a decree or order from which an appeal is pending, the Appellate Court may, on sufficient cause being shown by the appellant, req11ire security to be taken for the restitution of any property which may be or has been taken in execution of the decree or order for the payment of the value of such property and for the due performance of the decree or order of the Appellate Court.
