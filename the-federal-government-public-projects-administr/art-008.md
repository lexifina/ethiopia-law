# Article 8: Project Identification and Preliminary Selection or Screening
1/ Any project implementing body shall prepare project concept note, in a manner which would be useful for preliminary selection or screening, for project ideas identified by it.
2/ Any project shall only proceed to preliminary selection or screening when it is completed and submitted as per the basic criteria of project identification under Article (7) of this Proclamation.
3/ Any project shall only proceed to pre-feasibility or feasibility study, prioritization and selection cycles where it has been accepted through independent project feasibility review.
